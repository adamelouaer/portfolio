# Portfolio — Adam Elouaer

Portfolio personnel responsive en HTML, CSS et JavaScript, rédigé en français à partir des informations présentes dans le CV.

## Prévisualiser le site
Ouvre simplement `index.html` dans un navigateur. Une connexion internet est nécessaire pour charger les polices Google Fonts ; le site fonctionne aussi sans elles.

## Publier sur GitHub Pages
1. Crée un dépôt GitHub nommé `portfolio`.
2. Dépose `index.html`, `style.css`, `script.js`, `cv-adam-elouaer.pdf` et `README.md` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Dans **Build and deployment**, sélectionne **Deploy from a branch**, puis `main` et `/ (root)`, et enregistre.
5. Attends la fin du déploiement. L'adresse sera `https://adamelouaer.github.io/portfolio/`.

## Personnalisation importante avant publication
- Ajoute tes vrais projets dans la section `#projets` : titre, objectif, technologies, résultats et lien du dépôt. Ne présente pas de projets non réalisés comme s'ils étaient terminés.
- Tu peux retirer le numéro de téléphone si tu préfères ne pas le publier en ligne.
- Vérifie toutes les coordonnées et les informations de formation avant publication.
- Le CV téléchargeable se trouve dans `cv-adam-elouaer.pdf` ; remplace ce fichier pour mettre le CV à jour (garde le même nom).

## Structure
- `index.html` : contenu et sections du portfolio
- `style.css` : design responsive
- `script.js` : menu mobile
- `cv-adam-elouaer.pdf` : CV téléchargeable depuis la page d'accueil
